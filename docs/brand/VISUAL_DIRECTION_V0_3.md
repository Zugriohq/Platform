# Zugrio Visual Direction v0.3 — Dark-First, Palette Reopened

Status: **visual structure retained; brand color direction reopened by founder**.  
Supersedes the color recommendation in `VISUAL_DIRECTION_V0_2.md`.

## 1. What remains accepted

The following visual direction remains valid:

> **Premium dark-first financial workstation, technically mature, calm under pressure, dense but legible, with bright accents only where they earn attention.**

Retain:
- deep near-black / graphite foundation;
- premium material hierarchy;
- strong white/neutral typography;
- disciplined spacing;
- low-noise navigation;
- minimal decorative glow;
- clear analytical vs authority boundaries;
- semantic trading/status colors separate from brand identity;
- world-class microcraft.

## 2. What is rejected

The previously proposed:
> electric periwinkle / cobalt-violet

is **not an approved Zugrio brand direction**.

Do not treat the v0.2 purple/periwinkle tokens as canonical, preferred or default in future exploration.

Existing prototypes using them are evidence about layout only.

## 3. Color research question

The next exploration should determine which color identity best supports:

- premium / sophisticated;
- contemporary 2026 technology;
- serious financial use;
- long-session comfort;
- distinction from generic fintech blue;
- distinction from crypto neon/gaming;
- no collision with profit/loss, caution, safety, research or execution semantics;
- credible use across product, marketing, mobile, reports and investor material.

Color must be selected **after** testing it inside actual product states, not from a palette card alone.

## 4. Palette exploration constraints

Work should explore at least 4 distinct brand-color strategies, including:

### A. Neutral-led / almost colorless brand
Near-black + exceptional typography/material + one rare accent.

Question:
Can Zugrio become recognizable primarily through object grammar and material rather than color?

### B. Cool high-energy accent
A cool luminous family that is not simply generic fintech blue and does not reuse the rejected periwinkle direction.

### C. Warm high-energy accent
A warm identity color that avoids direct confusion with adverse/caution semantics through hue, value, context and restrained use.

### D. Unexpected spectral / dual-tone system
A distinctive non-semantic identity treatment using a controlled paired spectrum or contextual spectral effect, without becoming gradient-heavy crypto UI.

Do not assume any of these wins.

## 5. Semantic separation remains non-negotiable

Brand identity must remain distinct from:
- positive / favorable;
- negative / adverse;
- caution;
- information;
- unavailable;
- research-only;
- released/locked;
- BUY/SELL;
- ALLOW/BLOCK.

Every consequential state must remain understandable without brand color.

## 6. Modernity rule

Color does not make Zugrio modern.

Modernity must come first from:
- hierarchy;
- responsiveness;
- adaptive/contextual layout;
- direct manipulation;
- progressive disclosure;
- system-status clarity;
- precision typography;
- state maturity;
- motion quality;
- speed;
- personalization;
- microcraft.

A visually trendy color system on a static dashboard is not acceptable.

## 7. Material direction

Continue exploring:
- matte dark canvases;
- subtle surface elevation through value rather than shadow;
- fewer separators;
- crisp local highlights;
- strong selected-object focus;
- controlled translucency only for transient overlays;
- visual calm during prolonged sessions.

Test on:
- ordinary Windows laptop;
- high-DPI desktop;
- mobile OLED;
- lower-quality external display.

## 8. Brand recognition target

Zugrio should remain recognizable in monochrome through:
- Decision Case architecture;
- Decision Thread;
- Scope Frame;
- Mandate Boundary;
- typography;
- spacing;
- component behavior.

Color should amplify identity, not create it.
