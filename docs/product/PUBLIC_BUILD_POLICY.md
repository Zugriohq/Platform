# Public Build / Social Traction Policy

Building in public may create distribution, recruiting and investor signal, but it must not leak intellectual property, security detail or unvalidated trading claims.

## Safe public themes

- product problem and user workflow;
- UI progress;
- architecture at a safe abstraction level;
- broker-neutral infrastructure lessons;
- founder/product-building journey;
- waitlist and beta recruitment;
- measurable product milestones.

## Do not publish

- credentials or tokens;
- exploitable endpoint/security detail;
- proprietary thresholds not intended for publication;
- customer/account information;
- unvalidated win-rate or return claims;
- language implying guaranteed profitability.

Track activity as a product funnel:

`impressions → landing-page visits → waitlist → interviews → qualified beta users → activated users → paid users`.

Vanity engagement without customer evidence is not traction.
