# Threat Model

Security threat modeling will be maintained here as implementation surfaces are introduced.

Priority surfaces include:
- authentication and authorization;
- broker OAuth/credentials;
- signed execution intents;
- account isolation;
- replay/idempotency;
- secrets and key management;
- update/supply-chain integrity;
- desktop/connector boundaries;
- market-data integrity;
- admin/support access.

Threat-model changes that affect execution authority or customer capital require explicit review and tests.
