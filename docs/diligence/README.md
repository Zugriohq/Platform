# Diligence

This directory will hold human-readable technical-diligence material that can be generated from repository evidence, such as:
- architecture overview;
- dependency and licence inventory;
- security posture;
- release/change controls;
- IP provenance notes;
- validation/evidence index;
- operational ownership map.

Investor diligence material must not overstate product maturity, performance, regulatory status or production scale.
