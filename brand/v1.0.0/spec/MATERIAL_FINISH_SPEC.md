# Zugrio V1 Metallic Material Specification

Character: **machined / brushed silver** - premium, restrained and institutional.

## Approved qualities

- directional metal grain;
- controlled specular peaks;
- subtle upper-edge highlight;
- restrained depth / extrusion shadow;
- soft optical falloff;
- light that responds to letter contours.

## Avoid

- mirror chrome;
- liquid mercury;
- plastic;
- foil;
- rainbow / iridescent reflection;
- glitter;
- exaggerated bloom;
- generic loading shimmer.

The metallic finish is not a second logo. It is a material treatment of the canonical wordmark geometry.
