# Zugrio Brand Assets V1.0.0

Canonical geometry: `master/ZUGRIO_WORDMARK_MASTER.svg`.

This directory is the human-editable source of truth for the Zugrio V1 identity.

Rules:
- one wordmark geometry;
- path-only vector master;
- no font substitution;
- no AI regeneration as master;
- flat, metallic, ghost, monogram and motion treatments derive from the same paths;
- the Z monogram is supporting only.

Free authoring/review path: Inkscape + GitHub.
Professional tools such as Illustrator may open and edit the same SVG without changing the source hierarchy.

Core colors:
- Obsidian Black #050508
- Graphite #1A1A1A
- Steel Silver #C8CCD0
- Soft White #F5F5F7
