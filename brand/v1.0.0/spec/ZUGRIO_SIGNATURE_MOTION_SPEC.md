# Zugrio Signature Motion V1

The opening reveal is a contour-aware specular treatment, not a loading shimmer.

Sequence:
1. dark emergence: 0.45-0.65 s
2. primary grazing light: 1.05-1.30 s
3. local contour catches on Z / G / R / O
4. residual highlight decay: 0.25-0.45 s
5. settle and page reveal: 0.40-0.60 s

Target total: 2.3-2.9 s.

Material: brushed / machined silver. Avoid mirror chrome, liquid metal, foil, glitter and exaggerated lens flare.

Reduced motion: final mark + short opacity transition only.

Never deform the geometry to create motion.
